# Keyboard E-Commerce Website

This project was built as the final project for my program.

## Features

Fully functioning pages with cart and checkout feature, ability for guest checkout as well as Login and Sign Up.

### `npm i`

Please use npm i to install the necessary packages, navigate to final-project-api in my Github and clone that as well to get that backend working.

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will reload if you make edits.\
You will also see any lint errors in the console.
